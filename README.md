# 5 Day Plantation Shutters

HTML/CSS homepage draft for the existing Largo-based business. No frontend framework or build dependency.

Preview with `python3 -m http.server 4173 --bind 127.0.0.1`, then open http://127.0.0.1:4173.

This is a review draft, not a production replacement. It intentionally uses `noindex, nofollow`. The production canonical remains https://fivedayplantationshutters.com/.

Existing product, county, legal and contact pages remain linked on the live domain. Estimate buttons use the working existing contact page; this draft does not collect or pretend to submit leads. No live domain or hosting configuration is changed.

See docs/launch-checklist.md for remaining migration work and assets/SOURCES.md for provenance.
